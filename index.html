Structural caveats
  • Requests / Bid Rate / RPM cannot be split by channel — bid inputs are recorded before a channel is assigned, so channel-level demand volume is measured in bids.
  • HB Win Rate reads 0% on non-header-bidding integrations (e.g. elconfidencial.com) — it only measures the on-page header-bidding step; use Auction Win Rate (wins / bids) for all source types.
  • Bid Inputs, Bid Rate and RPM are structurally NULL at channel grain — bid inputs are counted before a channel is assigned; the columns are kept in Section 4 for audit but render as —.
  • Publisher-reported impressions lag ~3 days — CPM for the most recent days is provisional; missing values render as —, never as 0.

3 · Publisher head-to-head (both channels) i
SQL Query
-- @user:juanperez@seedtag.com @skill:barbi
WITH both_pubs AS (
  SELECT publisher_name
  FROM st_datalakehouse.analytics.etl_ssp_supply_funnel_daily_local
  WHERE date BETWEEN DATE '2026-07-01' AND DATE '2026-08-02'
    AND channel_id IN ('MagniteDirect','Rubicon')
  GROUP BY 1
  HAVING SUM(CASE WHEN channel_id='MagniteDirect' THEN revenue_st_eur ELSE 0 END) > 0
     AND SUM(CASE WHEN channel_id='Rubicon' THEN revenue_st_eur ELSE 0 END) > 0
)
SELECT f.publisher_name, f.channel_id, f.date,
  SUM(f.revenue_st_eur) AS gross_eur,
  IF(SUM(f.imps_paid)=0, NULL, SUM(f.publisher_revenue_eur)*1000.0/SUM(f.imps_paid)) AS cpm,
  IF(SUM(f.wins)=0, NULL, SUM(f.hb_wins)*1.0/SUM(f.wins)) AS win_rate
FROM st_datalakehouse.analytics.etl_ssp_supply_funnel_daily_local f
JOIN both_pubs b ON f.publisher_name = b.publisher_name
WHERE f.date BETWEEN DATE '2026-07-01' AND DATE '2026-08-02'
  AND f.channel_id IN ('MagniteDirect','Rubicon')
GROUP BY 1,2,3 ORDER BY 1,2,3

Source: Daily supply funnel — publishers with Gross Revenue on both Rubicon and MagniteDirect, all products, 2026-07-01 – 2026-08-02, revenue in EUR. Rows sorted by MagniteDirect Gross; MagniteDirect rows tinted coral; — = no data / provisional (impressions lag).

4 · Funnel health by publisher & source type i
SQL Query
-- @user:juanperez@seedtag.com @skill:barbi
WITH magnite_publishers AS (
  SELECT DISTINCT publisher_name
  FROM st_datalakehouse.analytics.etl_ssp_supply_funnel_daily_local
  WHERE date BETWEEN DATE '2026-07-01' AND DATE '2026-08-02'
    AND channel_id = 'MagniteDirect'
    AND source_type IS DISTINCT FROM 'Beachfront'
)
SELECT
  f.channel_id,
  f.editorial_group_name,
  f.publisher_name,
  f.source_type,
  SUM(CASE WHEN f.source_type IN ('Tag', 'SingleAdUnitTag', 'Amp', 'App')
           THEN f.bi_without_refresh
           ELSE f.bi_with_refresh END)                                 AS bid_inputs,
  SUM(f.bids)                                                          AS bids,
  SUM(f.wins)                                                          AS wins,
  SUM(f.hb_wins)                                                       AS hb_wins,
  SUM(f.imps_sold)                                                     AS imps_sold,
  SUM(f.revenue_st_eur)                                                AS gross_revenue_eur,
  SUM(CASE WHEN f.product_short_code LIKE 'O%' THEN f.revenue_st_eur ELSE 0 END) AS omp_gross_revenue_eur,
  IF(SUM(CASE WHEN f.source_type IN ('Tag', 'SingleAdUnitTag', 'Amp', 'App')
              THEN f.bi_without_refresh ELSE f.bi_with_refresh END) = 0, NULL,
     SUM(f.wins) * 1.0 /
     SUM(CASE WHEN f.source_type IN ('Tag', 'SingleAdUnitTag', 'Amp', 'App')
              THEN f.bi_without_refresh ELSE f.bi_with_refresh END))   AS bid_rate,
  IF(SUM(f.bids) = 0, NULL, SUM(f.wins) * 1.0 / SUM(f.bids))           AS auction_win_rate,
  IF(SUM(f.wins) = 0, NULL, SUM(f.hb_wins) * 1.0 / SUM(f.wins))        AS hb_win_rate,
  SUM(CASE WHEN f.product_short_code LIKE 'O%' THEN f.revenue_st_eur ELSE 0 END) * 1000.0
  / NULLIF(SUM(CASE WHEN f.source_type IN ('Tag', 'SingleAdUnitTag', 'Amp', 'App')
                    THEN f.bi_without_refresh ELSE f.bi_with_refresh END), 0) AS rpm_eur
FROM st_datalakehouse.analytics.etl_ssp_supply_funnel_daily_local f
WHERE f.date BETWEEN DATE '2026-07-01' AND DATE '2026-08-02'
  AND f.channel_id IN ('Rubicon', 'MagniteDirect')
  AND f.source_type IS DISTINCT FROM 'Beachfront'
  AND f.publisher_name IN (SELECT publisher_name FROM magnite_publishers)
GROUP BY 1, 2, 3, 4
ORDER BY gross_revenue_eur DESC

Source: Daily supply funnel — MagniteDirect publishers on both Magnite channels, all products (OMP-only revenue also shown), 2026-07-01 – 2026-08-02, revenue in EUR. Funnel order: bid inputs → bids → wins → (HB only: hb wins) → imps sold. Bid Inputs / Bid Rate / RPM are structurally — at channel grain; HB Win Rate is blanked on non-HeaderBidding rows.
